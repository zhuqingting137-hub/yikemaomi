# 一刻猫咪 · 小程序骨架

## 怎么跑起来

1. 下载安装[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)（稳定版即可）。
2. 打开工具 → 「导入项目」→ 选择本文件夹（`miniprogram/`）。
3. 没有注册小程序账号时选「测试号」/游客模式即可预览；正式开发时替换 `project.config.json` 里的 `appid`。
4. 编译后即可看到：猫1 在页面上，手指按住屏幕，火腿肠出现在指尖，猫跑过去并跟着手指走；松手 3 秒后火腿肠消失、猫回家；顶部 15 分钟倒计时，到点弹结束页。

## 当前是什么

- 骨架版：Canvas 精灵动画 + 触屏跟手 + 15 分钟计时 + 结束页占位。
- 素材为占位：猫（侧身全身透明图）、火腿肠来自新三视图；沙发/背景待后续生成"空房间场景图"后替换。
- 猫2 待素材到位后加入（改 `pages/index/index.js` 里的 `CATS` 数组）。

## 素材替换（后续）

动作帧序列（白底、同一只猫、侧身全身）就位后，填入 `CATS` 的 `idleFrames` / `walkFrames`，渲染时按帧切换即可，不用改交互逻辑。
