# 一刻猫咪

手机互动小站：三只猫咪，点击/滑动可切换，15 分钟互动计时。

## 页面

- `index.html`：三猫页面（照片占位，放入视频后自动切换播放）
- `猫1互动演示.html`：猫1（断尾伤腿狸花猫）实时互动演示——手指点哪里，火腿肠出现在哪里，猫会跑过去并跟着手指走，松手 3 秒后回沙发

## 素材结构

- `assets/video/cat1/ idle1.mp4 react1.mp4 sleep.mp4`（猫1，竖屏 9:16）
- `assets/video/cat2/`、`assets/video/cat3/` 同理
- `assets/img/`：猫照片、首帧图、互动素材（透明底猫/沙发/火腿肠）

视频生成提示词见 `视频生成提示词.md`。
