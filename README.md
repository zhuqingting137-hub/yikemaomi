# 一刻猫咪

手机互动小站：两只猫咪（蹩脚狸花猫、埃及法老猫），点击/滑动可切换，15 分钟互动计时。

## 页面

- `index.html`：两只猫页面（照片占位，放入视频后自动切换播放）
- `cat1-demo.html`：猫1 跟手互动版（制作中占位，动作帧素材到位后启用）

## 素材结构

- `assets/video/cat1/ idle1.mp4 react1.mp4 sleep.mp4`（猫1，竖屏 9:16）
- `assets/video/cat2/ idle1.mp4 react1.mp4 sleep.mp4`（猫2，竖屏 9:16）
- `assets/img/`：猫照片（压缩版 jpg）、首帧图、互动素材（透明底猫/沙发 webp、火腿肠 png）
